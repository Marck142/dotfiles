# Модульный Lua-конфиг Hyprland

Точка входа: `~/.config/hypr/hyprland.lua`.
Настройки разбиты на модули в `lua57/configs/`.

## Структура

```text
hyprland.lua
lua57/
  configs/
    settings.lua             клавиатура, ввод, курсор, системные параметры
    decoration.lua           оформление из выбранного профиля
    configs.lua              обычный профиль оформления
    configs_noanimation.lua  профиль без анимаций
    colors.lua               актуальные цвета Pywal из colors.json
    state.lua                независимое состояние переключателя анимаций
    exec.lua                 автозапуск через событие hyprland.start
    environment.lua          переменные окружения
    monitor.lua              HDMI-A-1 и HDMI-A-2
    tags.lua                 теги приложений
    wrules.lua               правила окон, слоёв и рабочих столов
    keybinds.lua              бинды через нативные hl.dsp
    actions.lua               действия, которым нужен Lua callback
  scripts/
    animations_toggle.sh     меняет только новое state.lua
    settings.sh              меню параметров для нового configs.lua
    waybar-layout.sh         не редактирует старое wrules.conf
    powermenu.sh              выход через нативный Lua-диспетчер
    powermenu_theme_select.sh выбор темы нового меню питания
```

Все модули подключаются через `require("lua57.configs.…")`, а не `source`.
Модули, подключённые через `require`, отслеживаются самим Hyprland.
Значения обычного профиля меняются в `configs/configs.lua`.
Раскладки и способ переключения находятся в `configs/settings.lua`.
Сохранены `us, ru` и переключение через Super+Space.

## Проверка и запуск

Проверить без запуска рабочего стола и программ автозапуска:

```sh
Hyprland --verify-config -c ~/.config/hypr/hyprland.lua
```

Ожидаемый результат: `config ok`.

Запустить отдельную новую сессию с этим конфигом из TTY после выхода из
текущей графической сессии:

```sh
Hyprland -c ~/.config/hypr/hyprland.lua
```

После явного запуска с `-c` обычный `hyprctl reload` перезагружает именно
выбранный конфиг. Не запускай новую сессию из терминала внутри текущего
Hyprland для проверки синтаксиса: для этого достаточно `--verify-config`.

## Совместимость и сохранённое поведение

Конфиг использует настоящий Lua API Hyprland: `hl.config`, `hl.bind`,
`hl.dsp`, `hl.monitor`, `hl.window_rule`, `hl.layer_rule`, `hl.workspace_rule`,
`hl.curve`, `hl.animation`, `hl.env`, `hl.on`.

Синтаксис проверен установленным Hyprland 0.57. Повтори команду проверки
после обновления Hyprland.

- F12 делает скриншот; обновление системы запускается через Super+Shift+U.
- Необъявленные `$ALT` и `$CONTROL` заменены настоящими модификаторами.
- Повторяемые бинды используют `repeating`, перетаскивание мышью использует
  `mouse`. Resize изменяет размер относительно текущего, как исходный бинд.
- Исходные switch-бинды сохранены без замены на touchpad-жесты. Комментарий
  старого файла называл их жестами, но `switch:` обозначает события устройств.
- Имена правил тегов и окон стали уникальными, чтобы они не перезаписывали
  друг друга в Lua API. Условия и эффекты сохранены.
- Исходный `workspaceopt allfloat` уже удалён upstream. На Super+Alt+V
  новый callback переключает существующие окна активного рабочего стола:
  смешанный/тайловый режим становится floating, полностью floating становится
  тайловым. Будущие окна этим действием не затрагиваются.
- Lua-параметр тачпада называется `tap_to_click`, а не `tap-to-click`.
- Цвета читаются из `~/.cache/wal/colors.json` при загрузке и reload.
  Когда кэша нет, используются цвета, действовавшие при переносе.
  Отдельные Lua-шаблоны Pywal и сторонние Lua JSON-библиотеки не нужны.
- Автозапуск выполняется только при событии `hyprland.start`, а не на
  каждом reload или при проверке конфига.
- Как и в исходнике, правила прозрачности окон используют обычный профиль
  даже при выключенных анимациях. Общие параметры оформления переключаются
  на `configs_noanimation.lua`.

Большинство команд по-прежнему используют твои существующие скрипты и
приложения. Их реальное выполнение не тестировалось: рабочая сессия не
перезапускалась, приложения и службы не запускались.

Отдельные копии созданы только там, где требовалось заменить редактирование
старого Hyprland-конфига или старую команду выхода. Меню параметров, как и
раньше, также меняет оформление Rofi и Dunst. Переключатель анимаций,
напротив, меняет только новый Lua-файл состояния.

Обои управляются Skwd: Super+W выбирает случайные обои, Super+Shift+W
открывает или закрывает выбор. `startup.sh` не запускает awww; при наличии
текущих обоев он обновляет кэш и цвета через `pywal.sh`.

В Lua-режиме старые команды вида `hyprctl dispatch workspace 3`
не поддерживаются. Внутренние бинды используют `hl.dsp`, а копия меню
питания использует `hyprctl dispatch 'hl.dsp.exit()'`. Если внешний инструмент
генерирует старые команды диспетчеров, ему нужна поддержка Lua API.
Совместимость внешних Pyprland, панелей и их собственных конфигов с будущим
Hyprland зависит от версий этих программ и не является результатом
проверки синтаксиса этого конфига.
